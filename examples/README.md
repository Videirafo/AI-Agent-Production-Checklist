# Projetos executáveis

## Safe Agent API

**[Abrir projeto →](./safe-agent-api/README.md)**

API FastAPI executável para estudar tenant isolation, tool policies, approval gates e testes de segurança sem precisar de chave de API de IA.

```bash
git clone https://github.com/Videirafo/AI-Agent-Production-Checklist.git
cd AI-Agent-Production-Checklist/examples/safe-agent-api
code .
```

Depois crie o ambiente virtual, instale `.[dev]`, rode `fastapi dev` e `pytest` conforme o README do projeto.

O CI executa a suíte pytest a cada alteração no exemplo.
